The JetBrains Git tools,
as a free standalone app

GitClient is an open-source Git GUI for Linux and Windows: commit graph, branches, hunk staging, interactive rebase and a 3-way merge editor — modeled on IntelliJ IDEA, for whatever editor you use.

Features

Commit graph & log

Virtualized history with lane graph, branch and tag labels, commit details and Monaco diffs. Tested on 100,000-commit repositories.

Search & filters

Filter by text, regex, hash, author, branch, date range and paths. Jump to any hash or ref.

Branches

Local and remote tree, favorites, smart checkout, merge, rebase, compare, fetch, pull, push and upstream tracking.

Interactive rebase

Reword, squash, fixup, drop and reorder in a dialog — with backup refs and one-click undo. Reset, revert, cherry-pick, reflog.

Commit window

Stage whole files or single hunks, discard, amend, sign-off, then commit and push in one step.

3-way merge tool

Correct Yours/Theirs labels for merge, rebase and cherry-pick, auto-resolve, per-chunk accept or remove, editable result, rerere.

Stash, blame, worktrees

Stash, file history, blame, tags, remotes, and full Git worktree management.

Nothing hidden

The Git Console shows every git command GitClient runs. No account, no telemetry, no cloud.

Install

Linux (Ubuntu, Debian, other distros)

curl -fsSL https://raw.githubusercontent.com/phil288/git-client/main/install.sh | bash

Windows 10 / 11 (PowerShell)

irm https://raw.githubusercontent.com/phil288/git-client/main/install.ps1 | iex

Both installers verify SHA-256 checksums. Prefer a manual download? Get the .deb, AppImage, .tar.gz or Windows installer from the latest release. Then open any repository with gitclient .

FAQ

Is GitClient free?

Yes. It is open source under the MIT license, with no paid tier, account or license key.

Can I use the IntelliJ / JetBrains Git tools without the IDE?

Yes — that is the point of GitClient. It reproduces the Log, Branches, Commit, interactive rebase and merge-conflict tools as a standalone app that works alongside VS Code, Neovim, Zed or the terminal.

Is there a good Git GUI for Linux?

GitClient runs natively on Linux (Ubuntu/Debian package, AppImage, tarball) and Windows, unlike Fork, Tower and Sourcetree, and is free and open source unlike GitKraken and Sublime Merge.

Does it work with GitHub, GitLab and Bitbucket?

Yes. It drives your installed git and uses your existing remotes, SSH keys and credential helpers, so it works with any Git host.
